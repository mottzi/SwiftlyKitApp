These logs and their accessibility snapshots are in the R2 evidence directory.
The additional signed multiple-window rehearsal reached build configuration
and an update offer, then failed to press the offered control through
accessibility automation. It did not establish the combined busy-workflow
result. The passing app tests verify operation counting across windows, duplicate
completion, idle callback ordering, and cancellation during discovery and
building. Source review confirms that tool installation, export, and cleanup
also register activity until their work returns. Those operations do not each
have a dedicated restart test. Those tests and the completed signed install/relaunch cases are the
available evidence; the combined signed busy-workflow case remains unverified.
The automation failure establishes a coverage limit, not a demonstrated app
failure.

After the rehearsal, all private app copies and both loopback feed servers were
closed. The original app preferences were restored and their parsed plist
matched the backup. `preferences-restored.txt` records the comparison.

SwiftlyKitApp `0.1.1` and earlier have no Sparkle support. Their users must install
Triple manually once. This migration and the new preferences domain are
documented in the prepared release notes.

## Accepted release verification, 2026-10-10

The owner accepted static code review together with the completed tests and
signed updater rehearsal as the release verification basis. The additional
signed busy-window rehearsal and a physical macOS 26.5 installation are no
longer release blockers. Their absence remains part of the evidence record.

Code review confirms one app-wide `AppActivity` instance shared by all build
windows. Discovery, tool installation, building, export, and cleanup register
operations before asynchronous work starts and end them after that work
returns. Sparkle's relaunch delegate queues installation while activity is
busy. Normal termination also waits for the same activity to become idle.
Passing tests cover two active operations, duplicate completion, reentrant
idle callbacks, and cancellation that waits for discovery or build work to
return. Completed signed rehearsal covers installation and relaunch, automatic
download, and installation on quit.

Both final app executable slices declare macOS 26.5 as their minimum. The
Triple library requires macOS 13; bundled Sparkle requires macOS 12. The
reviewed scene APIs are available by macOS 15. The successful archive targeted
macOS 26.5 and passed signing, notarization, and Gatekeeper checks. These
checks support the configured deployment target. They do not establish an
actual macOS 26.5 runtime result.

Source and dependency code are unchanged by the README rewrite. The existing
signed DMG remains the release candidate. Public dependency resolution still
follows approval to publish the library revision. Publication remains held.
