# Triple 0.2.0

Triple is the new name for SwiftlyKitApp. This release uses the Triple library
and adds automatic update checks through Sparkle. It builds and exports Linux
executables from local Swift packages.

## Install or upgrade

Download `Triple-0.2.0.dmg`, open it, and drag Triple to Applications. Triple
requires an Apple silicon Mac running macOS 26.5 or later.

If you use SwiftlyKitApp 0.1.1 or earlier, download and install Triple manually
once. Those versions do not support automatic updates. Quit SwiftlyKitApp before
installing Triple, and remove the old app when you have confirmed Triple works.
Triple starts with a new preferences domain, so configure your settings again.
Your projects, exported files, installed SDKs, and toolchains stay in place.

Future Triple releases can install through Sparkle. Automatic update checks are
on by default; automatic installation is off. Change either setting in Settings
or choose Check for Updates from the app menu. An update waits for active
configuration, tool installation, builds, exports, and cleanup before restarting.

## Changes

- Renamed the app, repositories, Swift modules, and command-line tool to Triple.
- Added Sparkle update checks, update preferences, and restart coordination
  across build windows.
- Added support for SwiftPM's default build system, including validation and
  export of Swift Build resource bundles.

The DMG attached to this release is signed with Developer ID and notarized by
Apple. Its checksums are in `SHA256SUMS.txt`.
